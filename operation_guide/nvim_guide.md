# Vim 与 LazyVim 实用指南

> 本文档基于 Vim 基础操作整理，并补充了 LazyVim（Neovim 发行版）中的常用增强功能。

---

## 1 进入 Vim

| 命令 | 说明 |
|------|------|
| `vim [文件名]` | 打开文件 |
| `vim -r` | 列出所有生成 `.swp` 文件的未保存内容 |
| `vim -r [文件名]` | 利用 `.swp` 文件恢复因异常退出而未保存的原文件 |
| `vim -R [文件名]` | 只读模式，打开文件，不允许修改 |

## 2 Vim 的命令模式

> **说明**：本文中的“命令模式”为 Vim 普通模式（Normal mode）和命令行模式（Command-line mode）的统称。打开 Vim 后默认进入命令模式。

### 2.1 进入/退出 Vim 的命令模式

#### 从命令模式进入编辑模式（插入模式）

| 命令 | 说明 |
|------|------|
| `i` | 在光标前插入 |
| `I` | 在当前行首插入 |
| `a` | 在光标后插入 |
| `A` | 在当前行尾插入 |
| `o` | 在当前行下方插入新行 |
| `O` | 在当前行上方插入新行 |
| `s` | 删除光标下的字符并进入编辑模式 |
| `S` | 删除当前行并进入编辑模式 |
| `c` | 修改（删除并插入）光标后的文本 |
| `C` | 修改（删除并插入）从光标到行尾的文本 |

#### 从编辑模式返回命令模式

- 按下 `Esc` 键
- 或按下 `Ctrl+c`

### 2.2 Vim 在命令模式下的用法

#### 2.2.1 退出 Vim

| 命令 | 说明 |
|------|------|
| `:w` | 保存文件 |
| `:wq` | 保存并退出 |
| `:q` | 退出（如果未修改文件） |
| `:q!` | 强制退出，不保存任何更改 |
| `ZZ` | 保存并退出（相当于 `:wq`） |
| `ZQ` | 强制退出，不保存（相当于 `:q!`） |

#### 2.2.7 宏和寄存器

**寄存器分类**

| 寄存器 | 说明 |
|--------|------|
| `a` 到 `z` | 普通寄存器，可存文本内容或宏 |
| `"` | 默认寄存器，用于普通的复制和粘贴操作 |
| `*` 和 `+` | 系统剪贴板寄存器，用于与系统剪贴板交互 |
| `0` | 复制寄存器，存储最近一次复制的内容，不会被删除操作覆盖 |
| `1` 到 `9` | 按时间存储最近依次删除的整行内容，`1` 为最近一次 |
| `-` | 用于存储最近一次小于整行的字符/单词删除 |
| `/` | 存储最近的搜索模式 |
| `:` | 存储最近的命令行历史 |

**查看寄存器**

| 命令 | 说明 |
|------|------|
| `:reg` | 列出所有已用的寄存器的内容 |
| `:reg 寄存器` | 仅列出该寄存器的内容（如 `:reg a`） |
| `:let @寄存器=""` | 清空该寄存器的内容（等号后为两个单引号） |

**复制粘贴到寄存器**

| 命令 | 说明 |
|------|------|
| `"ayy` | 将当前行复制到寄存器 `a` |
| `"aw` | 将光标后的单词复制到寄存器 `a` |
| `"ap` | 粘贴寄存器 `a` 的内容到光标后 |
| `"aP` | 粘贴寄存器 `a` 的内容到光标前 |

**录制宏**

| 命令 | 说明 |
|------|------|
| `qa` | 开始录制宏到寄存器 `a` |
| `q` | 停止录制 |
| `@a` | 执行寄存器 `a` 中的宏 |
| `@@` | 重复执行上一次的宏 |
| `n@a` | 重复执行寄存器 `a` 中的宏 n 次 |

## 4 LazyVim 增强功能

LazyVim 是基于 Neovim 的现代化配置发行版，在原生 Vim 基础上集成了大量插件和优化。以下是在 LazyVim 中常用的一些增强操作。

LazyVim 中的 `<leader>` 键默认是 **空格键（Space）**。文档中如 `<leader>ur` 表示先按空格，再依次按 `u` 和 `r`。

### 4.1 一些简单常用命令

#### 4.1.1 取消搜索高亮

在 LazyVim 中，搜索后所有匹配项会被高亮显示。若要清除高亮，可使用以下方法：

| 方法 | 说明 |
|------|------|
| **`Esc`** | 按下 `Esc` 键可快速清除搜索高亮（LazyVim 默认映射） |
| **`<leader>ur`** | 即按 `Space` + `u` + `r`，执行“重绘并清除搜索高亮” |
| **`:nohlsearch`** 或 **`:noh`** | Vim 原生命令，临时清除高亮，直到下次搜索 |

#### 4.1.2 文件比较（Diff）

此处使用 Neovim 内置 `vimdiff`（也可以使用一些相关插件等等）

- **从终端启动**：
  ```bash
  nvim -d file1.txt file2.txt
  ```
  这会直接打开并排的 diff 视图。

- **在 LazyVim 内启动**：
  
  1. 使用 `:vsp` 或 `:sp` 垂直或水平分屏打开两个文件。
  2. 在两个窗口间切换，分别执行 `:diffthis`。
  3. 此时两个窗口进入 diff 模式，高亮差异。
  4. 退出 diff 模式：执行 `:diffoff`。

#### 4.1.3 一次关闭所有窗口

1. **最快捷的方式：LazyVim 快捷键**

保存并退出所有文件：按 `<leader>qq`（即依次按下 空格键 + q + q）。

如果有未保存的更改，LazyVim 会提示你保存，按提示操作即可。

2. **标准 Vim/Neovim 命令**

如果你更习惯使用命令模式，可以在普通模式下按 `:` 进入命令行，然后输入以下指令：

| 使用场景                         | 命令   |
| :------------------------------- | :----- |
| **退出所有文件**（会提示保存）   | `:qa`  |
| **强制退出所有**（放弃所有更改） | `:qa!` |
| **保存所有文件并退出**           | `:wqa` |

#### 4.1.4 跳转函数定义并返回

在 LazyVim 中，基于 LSP（Language Server Protocol）实现智能代码导航。

| 操作 | 快捷键 / 命令 | 说明 |
|------|---------------|------|
| **跳转到定义** | `gd` | 将光标放在函数或变量上，按 `gd` 跳转到定义处 |
| **跳转到声明** | `gD` | 跳转到符号的声明处 |
| **跳转到类型定义** | `gy` | 跳转到类型定义处 |
| **查看引用** | `gr` | 列出当前符号的所有引用位置 |
| **悬浮显示文档** | `K` | 显示当前符号的文档或类型提示 |
| **返回之前的位置** | `Ctrl+o` | 在跳转列表中向后移动（回到上一个光标位置） |
| **前进到较新的位置** | `Ctrl+i` | 在跳转列表中向前移动（如果回退过头了） |

> **典型工作流**：使用 `gd` 跳转到函数定义查看实现，然后按 `Ctrl+o` 返回调用处。反复使用可在调用链中自由导航。

#### 4.1.5 自动换行

1. **临时启用**

​	按 **`<leader>uw`** 即可开/关自动换行

2. **永久开启**

   1. **找到配置文件**：打开 LazyVim 的选项配置文件，路径通常是 `~/.config/nvim/lua/config/options.lua`。

   2. **添加配置**：在文件中添加或修改以下行：

      ```lua
      -- 启用自动换行
      vim.opt.wrap = true
      ```

   3. **保存并重启**：保存文件后，重启 Neovim 或重新加载配置即可生效。

### 4.2 neo-tree管理文件及窗口操作

#### 4.2.1 管理文件

在 `neo-tree` 窗口中获得焦点后，可以使用以下快捷键进行文件操作。

| 操作              | 快捷键      | 说明                                                         |
| :---------------- | :---------- | :----------------------------------------------------------- |
| **新建文件/目录** | `a`         | 在光标所在目录下新建。输入文件名，以 `/` 结尾则创建目录。    |
| **删除**          | `d`         | 删除当前选中的文件或目录。                                   |
| **重命名**        | `r` 或 `m`  | 重命名当前文件或目录。                                       |
| **复制粘贴**      | `c`         | 复制选中的文件/目录，输入目标目录及自定义的文件名，自动粘贴  |

### 4.3 快速注释多行

以lua文件注释在代码前加--为例。（nvim的配置文件格式为lua）

#### 4.3.1 注释整个文件

如果你想注释掉当前打开的整个 `example.lua` 文件：

1. 在普通模式下（按 `Esc` 确保退出插入模式）。
2. 依次按下键盘：**`gg`**（跳到文件头） + **`VG`**（选中到文件尾，注意 `V` 是大写，`G` 是大写）。
3. 按下 **`gc`**（注释切换）。整个文件每一行前面都会被加上 `--`。

> **再次操作**：如果之后想取消所有注释，同样是选中所有行（`ggVG`），再按一次 `gc`，注释就会消失（因为 `gc` 是切换开关）。

#### 4.3.2 注释选中的特定区域

如果你只想注释掉配置文件里冲突的那几段（而不是整个文件）：

1. 将光标移动到你想注释的**第一行**。
2. 按下 **`v`**（进入行可视模式），或者按 **`Ctrl + v`** 进入块可视模式。
3. 按 `j` 或 `k` 向下/向上移动光标（或者按一次`j/k`命令，待选命令区域消失后：使用`ctrl+u/ctrl+d`来快速上下移动选择，或者用`数字+G`直接跳转到指定行，即选择到指定行）直到选中想要注释的所有行。
4. 按下 **`gc`**。

#### 4.3.3 注释单个或多个具体行

- **注释单行**：在普通模式下，按 **`gcc`**（连续按两次 `gc`），当前行会被注释。
- **注释多行（数字法）**：比如你想注释下面的 5 行，输入 **`5gcc`**，光标所在的当前行及下面 4 行（共 5 行）会被批量注释。

#### 4.3.4 使用 Vim 经典“块选择”（适合注释特定列）

如果你只想在代码的特定位置插入 `--`（比如统一对齐）：

1. 将光标移到你要插入注释符号的起始列。
2. 按 **`Ctrl + v`** 进入块可视模式。
3. 按 `j`/`k` 向下选择多行。
4. 按 **`I`**（大写的 i），输入 `--`（注意后面有个空格）。
5. 按 **`Esc`** 键，稍等片刻，所有选中的行都会在那一列被批量插入 `--`。（重要！！！不按Esc，不会把--复制到所有行）
