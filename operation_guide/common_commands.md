# 常用命令及操作

## 1 全局

| 快捷键                         | 操作说明                              |
| :----------------------------- | :------------------------------------ |
| `win`                          | 宏观视角打开工作区                    |
| `win` + `h`                    | 将窗口收起                            |
| `win` + `a`                    | 用 wofi 打开应用列表，按 `Esc` 可关闭 |
| `win` + `t`                    | 打开 GNOME 原始默认终端               |
| `win` + `g`                    | 打开 kitty 终端                       |
| `alt` + `v`                    | 打开剪贴板历史                        |
| `alt` + `w`                    | 关闭窗口                              |
| `ctrl` + `shift` + `n`         | 打开新的终端窗口                      |
| `ctrl` + `w`                   | 关闭浏览器标签页                      |
| `ctrl` + `shift` + `t`         | 恢复刚被关闭的浏览器标签页            |
| `ctrl` + `shift` + `alt` + `r` | 录屏                                  |
| `ctrl` + `shift` + `r`         | kooha 录屏                            |
| `F1`                           | snipaste 截屏，按 `F3` 可贴图         |

## 2 命令行

| 命令                                                         | 说明                                                         |
| :----------------------------------------------------------- | :----------------------------------------------------------- |
| `conda activate cli-tools`                                   | 进入 cli 工具的环境，之后在 shell 使用 `mergefile` 命令可以合并文件。 |
| `code+[目录/文件名]`                                         | 打开 VSCode。                                                |
| `fastfetch`                                                  | 按照 `~/.config/fastfetch/config.jsonc` 的配置打印系统信息。 |
| `fastfetch --config \<config\>`                              | 根据 `~/.local/share/fastfetch` 里的预设模式打印对应格式的系统信息（最开始更改配置的时候，把 `groups` 预设作为基调使用过，后续直接使用 `ff` 打印）。 |
| `ff`                                                         | 随机调用 `~/.config/fastfetch` 下的 `logo` 目录里的 logo，并打开 fastfetch。 |
| `fo`                                                         | 调用 `xdg-open` 在当前目录下打开 GUI 的文件资源管理器。      |
| `fo 目录/文件名`                                             | 调用 `xdg-open` 打开目标文件夹或文件。                       |
| `yazi`或`yy`                                                 | 打开终端文件管理器，yy在退出后可以留在当前目录，操作键位类似vim |
| `ls /boot/vmlinuz-* | grep -v rescue`                        | 查看自己的常规内核，以便后续删除某个内核。                   |
| `sudo grubby --set-default /boot/vmlinuz-7.0.6-100.legion.fc43.x86_64` | 指定对应内核为默认启动的内核。                               |
| `qqmusic`                                                    | 自动进入 `cli-tools` 的 conda 环境打开终端 QQMusicBox。      |
| `cava`                                                       | 在终端伴随音乐显示律动条。                                   |
| `opencode`                                                   | 在当前命令行打开 OpenCode。                                  |

## 3 一些工具中的操作

### 3.1 opencode中的快捷操作

| 快捷键 / 命令  | 作用                                                         |
| :------------- | :----------------------------------------------------------- |
| `@`            | **引用特定内容**：在输入框中输入 `@`，可以引用文件、文件夹或之前的对话，让 AI 更聚焦 |
| `/`            | **查看所有命令**：输入 `/` 会弹出命令列表，包括 `/init`（初始化项目）、`/connect`（切换模型）、`/help`（帮助）等 |
| `Ctrl + P`     | **打开命令面板**：与 VS Code 类似，快速访问各种功能和设置    |
| `Ctrl + A`     | **切换提供商 / 模型**：快速切换不同的 AI 服务商（你刚配置的 DeepSeek 就在这里） |
| `Ctrl + F`     | **收藏/标记**：可以收藏常用的模型或命令                      |
| `Tab`          | **切换 Agent 模式**：在 `agents` 和 `commands` 之间切换      |
| `方向键 ↑ / ↓` | **查看历史命令**：快速重复之前输入过的指令                   |
| `Ctrl + C`     | **取消当前正在执行的任务**（如果 AI 卡住了或执行了你不希望的操作） |
| `exit`         | 退出opencode                                                 |

### 3.2 shell窗口的快捷操作

| 快捷键                | 功能说明                                                     |
| --------------------- | ------------------------------------------------------------ |
| `Ctrl + A`            | 光标移动到**行首**（相当于按 Home 键）                       |
| `Ctrl + E`            | 光标移动到**行末**（相当于按 End 键）                        |
| `Ctrl + U`            | **删除从光标到行首**的所有字符（若光标在行末，则清空整行）   |
| `Ctrl + K`            | **删除从光标到行末**的所有字符                               |
| `Ctrl + W`            | 删除光标前的一个**单词**（以空格分隔）                       |
| `Ctrl + Y`            | 粘贴上一次由 `Ctrl+U` / `Ctrl+K` / `Ctrl+W` 删除的内容       |
| `Ctrl + L`            | **清屏**（相当于执行 `clear` 命令，但保留当前命令行）        |
| `Ctrl + C`            | 中断当前正在执行的命令；若在空行上输入，则取消当前输入的命令（换行后重新出现提示符，但不会删除已输入的内容） |
| `Ctrl + D`            | 退出当前 shell；若当前行有字符，则删除光标处的一个字符       |
| `Ctrl + R`            | 反向搜索历史命令（输入关键字即可查找）                       |
| `Tab`                 | 自动补全命令、文件名或路径                                   |
| `↑` / `↓`             | 浏览上一条 / 下一条历史命令                                  |
| `←` / `→`             | 向左 / 向右移动一个字符                                      |
| `Alt + B` / `Alt + F` | 向左 / 向右移动一个单词（部分终端需配置）                    |
| `Alt + D`             | 删除光标后的一个单词（从光标位置到词尾）                     |
| `Ctrl + /`            | 撤销上一步编辑操作                                           |

### 3.3 kitty终端的快捷操作

| 功能分类         | 快捷键                                | 说明                                                         |
| :--------------- | :------------------------------------ | :----------------------------------------------------------- |
| **标签页管理**   | `Ctrl+Shift+T`                        | 新建标签页                                                   |
|                  | `Ctrl+Shift+Q`                        | 关闭当前标签页                                               |
|                  | `Ctrl+Shift+Left` /  `Ctrl+Shift+Tab` | 切换到前一个标签页                                           |
|                  | `Ctrl+Shift+Right` / `Ctrl+Tab`       | 切换到后一个标签页                                           |
| **分屏窗口管理** | `Ctrl+Shift+Enter`                    | 新建分屏窗口                                                 |
|                  | `Ctrl+Shift+W`                        | 关闭当前选中的分屏窗口                                       |
|                  | `Ctrl+Shift+[`                        | 切换到上一个分屏窗口                                         |
|                  | `Ctrl+Shift+]`                        | 切换到下一个分屏窗口                                         |
| **布局管理**     | `Ctrl+Shift+L`                        | 在不同分屏窗口布局间循环切换（Tall/Stack/Grid 等）           |
| **广播功能**     | `Ctrl+alt+A`                          | 开启广播模式（已在 `kitty.conf` 中配置），在专用窗口中输入的命令会同步到所有分屏。按 `Ctrl+Esc` 结束广播。 |
| **其他**         | `Ctrl+Shift+F5`                       | 重新加载配置文件 `kitty.conf`                                |
|                  | `Ctrl+Shift+C`                        | 复制选中的文本                                               |
|                  | `Ctrl+Shift+V`                        | 粘贴文本                                                     |
|                  | `win+鼠标左键移动`                    | 拖动kitty窗口                                                |
|                  | `win+鼠标右键`                        | 打开kitty菜单                                                |

### 3.4 yazi的快捷操作

1. 导航与移动

| 快捷键 | 功能                       | 说明                  |
| :----- | :------------------------- | :-------------------- |
| `h`    | 返回上级目录               | 等同于 `Backspace` 键 |
| `l`    | 进入选中的目录 / 打开文件  | 等同于 `Enter` 键     |
| `j`    | 向下移动光标               |                       |
| `k`    | 向上移动光标               |                       |
| `gg`   | 跳转到列表顶部             |                       |
| `G`    | 跳转到列表底部             |                       |
| `H`    | 后退，回到上一个访问的目录 | 类似浏览器的“后退”    |
| `L`    | 前进，到下一个访问的目录   | 类似浏览器的“前进”    |
| `Tab`  | 预览文件内容               | 在右侧面板预览文件    |
| `Ctrl + f` | 向下翻一页 | 相当于 PageDown，跳转到当前屏幕的下一页。 |
| `Ctrl + b` | 向上翻一页 | 相当于 PageUp，跳转到当前屏幕的上一页。   |
| `Ctrl + d` | 向下翻半页 | 快速浏览时很好用，滚动幅度适中。          |
| `Ctrl + u` | 向上翻半页 |                               |

2. 文件与目录操作

| 快捷键     | 功能                          | 说明                                            |
| :--------- | :---------------------------- | :---------------------------------------------- |
| `y`        | 复制选中的文件                |                                                 |
| `x`        | 剪切选中的文件                |                                                 |
| `p`        | 粘贴文件（覆盖已存在文件）    |                                                 |
| `P`        | 粘贴文件（不覆盖，保留两者）  | 如果存在同名文件，会自动重命名新粘贴的文件      |
| `d`        | 删除文件（移至回收站/ trash） |                                                 |
| `D`        | **永久删除**文件              | **危险操作，谨慎使用**                          |
| `r`        | 重命名文件                    |                                                 |
| `a`        | 创建新文件或目录              | 输入名字时以 `/` 结尾则创建目录                 |
| `.`        | 切换显示/隐藏隐藏文件         | 即切换是否显示以 `.` 开头的文件                 |
| `enter`    | 以默认方式打开文件            | 目录/文本使用nvim打开，其他使用系统默认方式打开 |
| `鼠标左键` | 选择对应文件并预览            |                                                 |
| `鼠标左键` | 选择对应文件并以默认方式打开  |                                                 |

3. 选择与批量操作

| 快捷键     | 功能                                | 说明                                              |
| :--------- | :---------------------------------- | :------------------------------------------------ |
| `Space`    | 切换选中/取消选中当前文件           |                                                   |
| `v`        | 进入/退出**可视模式** (Visual Mode) | 在可视模式下，用 `j`/`k` 移动可以连续选中多个文件 |
| `V`        | 切换可视模式（另一种方式）          |                                                   |
| `Ctrl + a` | **全选**所有文件                    |                                                   |
| `Ctrl + r` | **反选**所有文件                    |                                                   |
| `Esc`      | 取消所有选中，或退出搜索/过滤模式   |                                                   |

4. 搜索、筛选与跳转

| 快捷键    | 功能                                  | 说明                       |
| :-------- | :------------------------------------ | :------------------------- |
| `/`       | 在当前目录下搜索文件                  | 输入关键词后实时筛选       |
| `?`       | 查找下一个匹配项                      | 用于在搜索结果中跳转       |
| `n` / `N` | 跳转到下一个/上一个匹配项             |                            |
| `f`       | 过滤当前目录的文件                    | 只显示匹配的文件           |
| `s`       | 使用 `fd` 工具按**名称**搜索文件      | 需要安装 `fd`              |
| `S`       | 使用 `ripgrep` 工具按**内容**搜索文件 | 需要安装 `ripgrep`         |
| `z` / `Z` | 使用 `zoxide` 或 `fzf` 快速跳转目录   | 需要安装 `zoxide` 或 `fzf` |

5. 标签页、排序与其他

| 快捷键     | 功能                         | 说明                                                         |
| :--------- | :--------------------------- | :----------------------------------------------------------- |
| `t`        | 创建一个新的标签页 (Tab)     |                                                              |
| `[` / `]`  | 切换到前一个/后一个标签页    |                                                              |
| `1`...`9`  | 切换到指定编号的标签页       |                                                              |
| `Ctrl + c` | 关闭当前标签页               |                                                              |
| `,`        | 打开排序菜单，按各种规则排序 | 如按名称、大小、修改时间等                                   |
| `~`        | 打开帮助页面                 | 可以快速查阅所有快捷键                                       |
| `q`        | **退出** Yazi                | **注意**：使用小写 `q` 退出，结合我们之前配置的 `yy` 函数，可以实现自动切换到退出时的目录 |
